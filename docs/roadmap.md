# Product roadmap

The goal is one useful view of local and explicitly connected AI activity, independently usable and consumable by Deep AI. Feature depth will grow through demonstrated user journeys.

| Stage | Scope | State |
| --- | --- | --- |
| Local foundation | Metadata ledger, hierarchy, chronology, tokens/costs, web/terminal views, filters, native file imports, read contract | Implemented alpha. Synthetic and fixture qualification. |
| Reliable daily use | Incremental cursors, source health details, correction protocol, retention controls, configurable evidence windows, deeper session drill-down and larger ledgers | Planned |
| Connected sources | Reviewed adapters for more coding tools, supported OpenTelemetry ingestion and authorized cloud exports | Planned. No new credentials or hooks installed. |
| Quota and budgets | Independently sourced provider quota windows, reset times and budget notifications, with cost provenance preserved | Planned. No quota-to-dollar inference. |
| Rich analysis | Hourly heatmaps, latency percentiles, failure/slow-tool views, comparisons, exports and transparent forecasts | Planned |
| Deep integration | Reviewed same-origin bridge and unified monitoring view beside existing owner activity | Consumer adapter supplied. Not applied or deployed. |

Public demos remain synthetic. A capability is implemented when its complete input-to-consumer journey works and its meaningful failure behavior is checked. Live personal-source qualification, user acceptance and production readiness remain separate evidence.
