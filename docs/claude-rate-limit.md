# Claude CLI rate-limit observations

The [Claude Agent SDK Python reference](https://code.claude.com/docs/en/agent-sdk/python) documents `RateLimitEvent` and a 0–1 utilization fraction. A task-owned Claude Code 2.1.308 `stream-json` invocation also supplied `unifiedWindows` with `five_hour` and `seven_day` utilization and reset fields. The nested `unifiedWindows` layout is an observed CLI format, not a cross-version guarantee. Monitoring reads it only from an explicitly piped invocation. It does not read credentials, query an account endpoint or start a model call.

Add `--quota-output /private/claude-rate-limit.json` to [structured-stream capture](claude-cli-stream.md). The command writes a new 0600 `monitoring.quotas.v1` file at stream end if a supported rate-limit event arrived. Supply `--quota-account ALIAS` if you want a local account label; it does not discover or verify account identity. Select that file separately with `top --quota-file` or `serve --quota-file`. Its event receipt time stays fixed when the file is reread. A missing frame leaves no file and reports `unavailable`.

The collector recognizes five-hour and seven-day windows, including documented model-specific seven-day names. It converts utilization to a 0–100 used percentage and retains each window's reset time and most recent event receipt time. Later valid events update only the windows they report. A malformed or mismatched event does not erase an earlier valid window; the receipt says `partial` and counts rejected events. The CLI exits nonzero for partial, failed or uncertain publication after draining the stream. Check the private output before retrying an uncertain write.

The source status (`allowed`, `allowed_warning` or `rejected`) is preserved in the provenance label. Raw session IDs, event UUIDs, overage and payment fields are discarded. A reported reset passing does not establish new capacity. An event may arrive only when rate-limit status changes, so no new event means **unknown current allowance**, not unchanged capacity. These windows are CLI-reported observations, not verified account billing, a subscription balance, spending permission or a provider enforcement control. Installed Claude Code 2.1.308 is the qualified format; other versions need a fresh source check.
