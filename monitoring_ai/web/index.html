LOCAL CONFIGURATION

Monitoring does not discover files or create a manifest in the browser. Use the CLI to choose authorized inputs and keep the manifest private.

Set up an explicitly selected source
  1. Choose a normalized JSONL stream, or a complete Claude Code or Codex session file that you own or are authorized to read. The dashboard never scans for files.
  2. Create a private manifest with the CLI. For normalized input:
    python3 -m monitoring_ai sources create --output /path/to/private-sources.json --file /absolute/path/to/authorized.jsonl --id my-input --format normalized
    For Claude or Codex, choose --format claude or --format codex and add a project alias such as --project my-app.
  3. Check the manifest, then start the server with it:
    python3 -m monitoring_ai sources check --sources /path/to/private-sources.json
python3 -m monitoring_ai serve --sources /path/to/private-sources.json --db /path/to/private-ledger.sqlite

See README.md sections “Connect your data” and “Detailed reports” for command details. Manifests and input files stay on your machine.
